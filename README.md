# H5 工具矩阵 · 自动化生产线

> 模式：**AI 负责侦察 + 决策 + 开发，用户只验收。**
> 每日 06:00 自动新增 3 个纯静态 H5 工具，长期铺成可搜索的工具矩阵，赢家再升级为小程序。

## 一、每日自动化流程（定时任务执行）

1. **侦察**：用 WebSearch/WebFetch 扫描公开信号——微信指数/百度指数上升长尾词、应用市场工具类差评、独立开发者社区需求、小红书/知乎高热度"求工具"帖。
2. **决策**：用评估矩阵筛选 3 个方向——中频需求（每周1–3次）/无强势头部竞品/适合 H5/个体户类目可行/AI 可自动化大部分开发。
3. **开发**：每个方向生成 1 个独立纯静态单页工具（自包含 `index.html`，内联 CSS+JS，无后端依赖，真实可用）。
4. **归档**：写入 `manifest.json` 并汇报当日新增与对应关键词。
5. **红线**：跳过去水印/破解/侵权/医疗诊断/金融建议类。

## 二、定时任务配置（在 WorkBuddy 创建）

```
名称：     H5工具矩阵·每日生产线
频率：     daily（每天 06:00）
Cron：     0 0 6 * * *
超时：     1800 秒（单任务上限）
Prompt：
  你负责把"H5 工具矩阵"生产线跑起来，全程自主决策，无需询问。
  步骤：
  1. 用 WebSearch/WebFetch 扫描公开信号：微信指数/百度指数上升长尾词（带场景/地域/人群的组合词优先）、应用市场"工具类"App 差评、独立开发者社区需求、小红书/知乎高热度"求工具/求解决方案"帖。
  2. 用评估矩阵为候选打分（每项1–5）：需求频率是否中频、是否无强势头部竞品、是否适合 H5 先行、个体户类目是否可行、AI 能否自动化大部分开发。取总分最高的 3 个方向。
  3. 为每个方向生成独立纯静态 H5 单页工具，要求：
     - 自包含 index.html（内联 CSS+JS，零后端依赖，零外部 API key）
     - 现代简约 UI：移动端优先、卡片圆角、柔和渐变，配色抽成 CSS 变量便于换肤
     - 含语义化 <title> 与 <meta name="description">，利于 SEO
     - 功能真实可用（纯前端 JS 实现）
     - 写入 /workspace/h5-apps/<slug>/index.html
  4. 更新 /workspace/h5-apps/manifest.json（新增 slug、名称、方向、关键词、生成日期）。
  5. 跳过：去水印/破解/侵权/医疗诊断/金融建议类。
  6. 汇报当日新增的 3 个工具名称与各自主攻关键词。
  注：本任务只在沙箱生成可部署源码，不负责公网部署（部署由用户另行完成）。
```

## 四、从"源码"到"别人搜得到"（部署到公网）

沙箱只能产出源码，**真正被搜索引擎收录需要你完成最后一步**：

1. **托管**：任选其一
   - 国际：GitHub Pages / Vercel / Netlify（免费，部署简单）
   - 国内（推荐，百度收录更快）：腾讯云/阿里云静态托管 + **已备案域名**
2. **绑定独立域名**（国内必须备案），把所有 `h5-apps/*` 作为子路径或子域名发布。
3. **SEO 基础**（每个页面已含 title/description，还需补）：
   - 根目录放 `sitemap.xml` 列出全部工具 URL
   - `robots.txt` 放行搜索引擎
   - 各页补充 Open Graph 标签
4. **提交收录**：百度搜索资源平台 / Google Search Console 提交 sitemap。
5. **持续喂养**：用定时任务每日向各工具页补充长尾内容/更新数据，保持活跃。

## 五、风格换肤

所有配色集中在每个文件顶部的 `:root{ --primary / --bg / --card … }`。
说一句"换成莫兰迪/赛博朋克/国风"，即可一键批量替换整组变量。
