# 2026-10-15 · 注入组件 i18n 改造完成

## 本次做了什么

把工具页统一组件（inject_components.py）里的**硬编码中文文案**全部替换为 `T()` 调用，实现 14 语言自动切换。

## 关键改动

1. `inject_components.py` VER 从 6 → 7（触发全量重注入）。
2. WB_I18N 字典（14 语言）此前已加入，本次把底部工具条、分享海报、评论区、付费墙的硬编码中文全部改为 `T('key')` 调用。
3. 语言自动检测：`WB_LANG` 读 `navigator.language` 前两位，匹配 14 语言之一则用之，否则回退英文。

## 修复的 bug

- 编辑付费墙 `showPay()` 时多了一个 `};`，导致 `blurPage` 处 `Unexpected token 'function'` 语法错误。已修复。
- 注入脚本幂等机制（MARK 检查）在 VER 不变时跳过，导致修复后无法重注入——手动剥离旧 v7 块后强制重注入解决。

## 验证结果

- 20 个工具全部注入 v7，JS 语法 `node --check` 全部通过（0 错误）。
- 部署到 GitHub Pages，全部文件返回 200。
- 线上门户 + qr-generator + text-diff 均 200。

## 14 语言清单

zh / en / ja / ko / es / fr / de / ru / pt / ar / hi / vi / th / id

## 遗留
